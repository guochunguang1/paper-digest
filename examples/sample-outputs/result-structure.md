# 结果对象结构描述（result-structure）

paper-digest 的产出全部为落盘文件，无内存大对象。体积标注：小 = 可直接入库；大 = 运行时中间产物，按需重跑生成。

## 1. `<PDF 名>_digest.html`（最终交付）

- **返回类型**：落盘文件（单文件自包含 HTML，UTF-8）
- **体积**：中到大（5–15 MB，随图数量与 `--zoom` 变化；图 base64 内嵌）
- **关键内容在哪儿**：依次为——meta 行（期刊/DOI/日期/页数/图数）→ 中文译题 + 英文原题（h1/p.en）→ 摘要中英对照（两个 `.box`）→ 研究背景与科学问题 → 方法要点 → 重点总结 → 逐图解读（每图一个 `figure.card`：内嵌 PNG + 英文图注 + 中文解读）→ 局限性与批判性评价 → footer 免责声明
- **可提取为轻量产物**：章节文本可再导出 Markdown；图可解 base64 复原 PNG

## 2. `extract/paper_text.md`（中间产物）

- **返回类型**：落盘文件（Markdown，纯文本）
- **体积**：视论文页数，通常 30–200 KB
- **关键内容在哪儿**：全文文本，页与页之间以 `<!-- ===== PAGE N ===== -->` 注释分页，供 LLM 回溯页码
- **大对象**：不入库，重跑脚本即得

## 3. `extract/manifest.json`（中间产物/清单）

- **返回类型**：落盘文件（JSON）
- **体积**：小（<20 KB）
- **关键结果与访问路径**：`pdf`（源路径）、`n_pages`、`zoom`、`figures[]`——每项含 `label`（"Figure 1"）、`num`、`page`（0-based）、`caption`（图注前 500 字符）、`png`（裁剪图路径）、`clip`（裁剪框 [x0,y0,x1,y1] pt）。质检门据此对账图数
- **可提取为轻量产物**：整份 JSON 可入库（见 sample-manifest.json）

## 4. `extract/figures/figNN.png`（中间产物）

- **返回类型**：落盘文件（PNG，`--zoom` 默认 2.2 ≈158dpi）
- **体积**：单个 0.3–1.5 MB
- **关键内容在哪儿**：整页宽或列宽裁剪的图区域（含图注首段）
- **可提取为轻量产物**：单张 PNG 可作示例入库（见 sample-fig05.png）；全套不入库
